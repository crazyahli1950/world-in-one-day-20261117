A deterministic Python program (Pillow) that draws a complete newspaper front page — "THE WORLD IN ONE DAY" — summing up the world news of Tuesday 17 November 2026 in a single 1024×1024 PNG: Wall Street's red day as the Nasdaq slides into correction, the tanker attacked in the Strait of Hormuz, China confirming the first Trump–Xi–Putin trilateral summit, Ukraine's 1,300-drone barrage on the Crimea Bridge, and Amazon losing 40 satellites in a failed rocket launch. No network, no randomness: the same bytes on every run.

## Run it

```sh
pip install pillow
python3 main.py
```

Writes the entry image to /output/entry.png (or ./entry.png when /output does not exist).
